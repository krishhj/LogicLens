💡 About Graph Algorithms

Overview

Graphs model nodes and edge connections for spatial routing, network analysis, topological dependencies, and MST trees.

  • BFS & DFS: Level-by-level queue exploration vs. deep recursion call stack traversal.
  • Dijkstra & A*: Priority Queue shortest path with edge relaxation and heuristic estimation.
  • MST (Kruskal & Prim): Disjoint-Set Union-Find edge sorting vs greedy tree expansion.
  • Topological Sort & Cycle Detection: Kahn's in-degree table and 3-color recursion stack tracking.
  • Floyd-Warshall & Tarjan's SCC: All-pairs distance matrix updates and low-link strongly connected components.
