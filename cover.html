Understanding Algorithmic Complexity

Algorithmic efficiency is measured in two dimensions: Time Complexity (execution speed) and Space Complexity (memory footprint). Big-O notation describes how these resource requirements scale as the input size N grows towards infinity.

Time Complexity

Measures the number of elementary operations executed by an algorithm relative to the input size N. Instead of timing in seconds (which varies by CPU hardware), it focuses on execution growth rate, ensuring algorithmic comparison remains standardized.

Space Complexity

Measures the total auxiliary memory required by the algorithm during execution, excluding the input dataset size itself. It counts dynamic variable allocations, auxiliary arrays, and memory frames allocated on the call stack due to recursion depth.

O(1) Constant
Formula: T(N) = c (Constant Operations)

The operation runs in a fixed number of steps, completely unaffected by the size of the input.

function getFirst(arr) { return arr[0]; // Exactly 1 lookup operation }
How to find: No loops or recursive calls are present. The index lookup uses direct address math: Base_Address + (Index * Element_Size), which executes instantly in 1 CPU step regardless of the array's length.
O(log N) Logarithmic
Formula: T(N) = log₂(N) (Halving search space)

The execution time increases linearly while the input size grows exponentially. The search space is halved at each step.

function binarySearch(arr, target) { let low = 0, high = arr.length - 1; while (low <= high) { let mid=Math.floor((low + high) / 2); if (arr[mid]===target) return mid; if (arr[mid] < target) low=mid + 1; else high=mid - 1; } return -1; }
How to find: Notice the loop counter variables. At each cycle, the distance between low and high is divided by 2. Finding the maximum loops: N / 2^k = 1. Solving for steps k yields k = log₂(N).
O(N) Linear
Formula: T(N) = a·N + b (Direct scale)

The workload grows in direct proportion to the size of the input. Double the input size, double the steps.

function findMax(arr) { let max = arr[0]; for (let i = 1; i < arr.length; i++) { if (arr[i]> max) max = arr[i]; } return max; }
How to find: Identify the loop bounds. The loop starts at i = 1 and increments by 1 until it hits arr.length (which is N). The loop block executes exactly N - 1 times, which simplifies to O(N).
O(N log N) Linearithmic
Formula: T(N) = N · log₂(N) (Split & Scan)

Common in efficient sorting algorithms. A linear step (N) is run at each level of a divide-and-conquer tree (log N).

function mergeSort(arr) { if (arr.length <= 1) return arr; const mid=Math.floor(arr.length / 2); const left=mergeSort(arr.slice(0, mid)); const right=mergeSort(arr.slice(mid)); return merge(left, right); // merge takes O(N) time }
How to find: The array of size N is recursively halved until size 1, forming a binary tree of height log₂(N). At each level of the recursion, the linear merge function performs O(N) comparisons. Sum: N * log₂(N).
O(N²) Quadratic
Formula: T(N) = a·N² + b·N + c (Nested)

Work grows proportionally to the square of the input. Double the input size, operations quadruple.

function checkDuplicates(arr) { for (let i = 0; i < arr.length; i++) { for (let j=i + 1; j < arr.length; j++) { if (arr[i]===arr[j]) return true; } } return false; }
How to find: Analyze nested loops. The outer loop runs N times. For each iteration, the inner loop runs N - i times. Total steps: (N-1) + (N-2) + ... + 1 = N(N-1)/2 = 0.5N² - 0.5N. Drop lower terms: O(N²).
O(2^N) Exponential
Formula: T(N) = c · 2^N (Binary branching)

Work doubles with each additional element in the input. Impractical for inputs larger than N ≈ 40.

function fibonacci(n) { if (n <= 1) return n; return fibonacci(n - 1) + fibonacci(n - 2); }
How to find: Analyze the recursion tree. Each function call branches into 2 subsequent recursive calls. For input size N, the tree grows to depth N. Total number of calls is approximately 2^0 + 2^1 + ... + 2^N = 2^(N+1) - 1, which is O(2^N).
How to Find Complexity Step-by-Step

Follow this mathematical recipe to extract precise time and space behaviors from any block of code.

Source Code Example
function searchMatrix(matrix, target) { let n = matrix.length; // 1. Scan diagonal items (Single Loop) for (let i = 0; i < n; i++) { if (matrix[i][i]===target) return true; } // 2. Scan entire grid (Nested Loops) for (let r=0; r < n; r++) { for (let c=0; c < n; c++) { if (matrix[r][c]===target) return true; } } return false; }
Time Complexity: O(N²)
  • 1
    Identify the input size metric: Here, N represents the dimensions of the square matrix (height and width).
  • 2
    Count operations in block 1: The diagonal-scanning loop runs exactly N times. So it executes O(N) operations.
  • 3
    Count operations in block 2: The nested loops iterate r from 0 to N and c from 0 to N. The inner body runs exactly N * N = N² times. So it executes O(N²) operations.
  • 4
    Combine & isolate dominant term: Summing both blocks gives T(N) = N + N² operations. As N grows to infinity, the linear term N becomes negligible compared to N². We drop constants and lower-order terms to yield O(N²).
Source Code Example
function generateMultiples(n) { let result = []; // 1. Recursive call stack helper function helper(current) { if (current > n) return; result.push(current * 2); helper(current + 1); } helper(1); return result; }
Space Complexity: O(N)
  • 1
    Separate Input from Auxiliary Space: Big-O space complexity focuses on extra memory (variables, lists, call stacks) allocated to solve the task, excluding the input size itself.
  • 2
    Measure Heap allocation: The algorithm constructs a dynamic array result which receives N elements, requiring O(N) heap memory.
  • 3
    Measure Call Stack allocation: The function helper calls itself recursively. For parameter N, the recursion depth is N stack frames deep. Each stack frame stores function pointers, parameters, and local states.
  • 4
    Sum and simplify: Total Auxiliary Space = O(N) (for the list) + O(N) (recursion call stack) = O(N) space.
