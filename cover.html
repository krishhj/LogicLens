Project Overview

LogicLens is an interactive developer learning platform and dry-run emulator. It translates complex program logic into dynamic, step-by-step graphical frames. By combining localized execution tracking with visual animations, LogicLens helps developers and computer science learners debug algorithms, inspect array transformations, and grasp memory flows intuitively.
