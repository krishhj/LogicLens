Time & Space Complexity

BST & AVL Trees

BST Search/Insert: O(log N) avg, O(N) worst. AVL Tree guarantees strict O(log N) operations via single and double rotations.

Min/Max Heap & Segment Tree

Heap Insert/Extract: O(log N). Build Heap: O(N). Segment Tree Build: O(N), Range Query & Point Update: O(log N).

Trie & Fenwick Tree (BIT)

Trie Word Operations: O(L) where L is word length. Fenwick Tree Query/Update: O(log N) with space complexity O(N).

Red-Black Tree & B-Tree

Red-Black Tree: Strict O(log N) with max 2 rotations per insert. B-Tree: Ideal for external storage with logarithmic height O(log_M N).

💡 About Trees & Tree Algorithms

Overview

Trees are hierarchical data structures optimized for search, range queries, indexing, dynamic sets, and prefix matching.

Tree Mechanics & Formulas

  • 1. Tree Traversals: Inorder (L-Root-R), Preorder (Root-L-R), Postorder (L-R-Root), and Level-Order (BFS).
  • 2. Min/Max Heap: Complete binary tree array representation where parent index is ⌊(i-1)/2⌋ and children are 2i+1, 2i+2.
  • 3. Trie (Prefix Tree): Character-level tree for fast dictionary lookups and auto-complete in O(L) time.
  • 4. Lowest Common Ancestor (LCA): The deepest node that has both node A and node B as descendants.
  • 5. Union-Find: Disjoint set forest with Find(x) (path compression) and Union(x, y) (union by rank) running in O(α(N)) nearly constant time.
  • 6. Segment Tree: Binary tree representing interval ranges for fast range sum/min/max queries and updates in O(log N).
  • 7. Fenwick Tree (BIT): Space-efficient tree using Least Significant One bit i & -i for prefix sums and point updates in O(log N).
  • 8. Red-Black Tree: Self-balancing BST using RED and BLACK nodes with recoloring and max 2 rotations per insertion.
  • 9. B-Tree: Self-balancing search tree containing multiple keys per node, optimized for disk systems and database indices.
