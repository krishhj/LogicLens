💡 About DP & Backtracking

Overview

Dynamic Programming solves overlapping subproblems using Tabulation (bottom-up) or Memoization (top-down). Backtracking systematically explores decision trees with branch pruning.

  • Coin Change & Knapsack: 1D/2D DP table evaluations with optimal sub-structure traceback.
  • LIS & MCM: Longest Increasing Subsequences and optimal matrix parenthesization.
  • Tower of Hanoi: Recursive disk transfers across 3 pegs.
  • Subsets & Permutations: Exponential $O(2^N)$ decision tree state space generation.
  • Rat in a Maze, N-Queens, Sudoku: Grid & board constraint satisfaction with pruned invalid states.
