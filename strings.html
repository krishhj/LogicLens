💡 About String Algorithms

Overview

String processing algorithms enable linear pattern matching, palindrome detection, multi-pattern trie searches, suffix sorting, and dynamic programming distance computations.

  • Z-Algorithm: Computes prefix match lengths using an expanding $[L, R]$ Z-box range.
  • Boyer-Moore: Scans right-to-left and uses bad-character skip heuristics for optimal shifts.
  • Manacher: Finds all maximal palindromes in linear $O(N)$ time by storing palindrome radii.
  • Aho-Corasick: Builds a Trie with failure links to match dictionary patterns simultaneously.
  • Suffix Array & LCP: Lexicographically sorts string suffixes and computes adjacent common prefix lengths.
  • Edit Distance & LCS: Dynamic programming table cell-by-cell evaluation with optimal traceback paths.
