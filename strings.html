💡 About String Matching Algorithms

Overview

String pattern matching locates all valid occurrence indices of a pattern string P of length M within a primary text body T of length N.

Algorithms & Mathematical Formulations

  • 1. Naive String Matching:

    Slides pattern P[0..M-1] across text T[0..N-1] at every possible alignment index i ∈ [0, N-M]. For each alignment, compares characters sequentially from left to right. When a mismatch occurs, shifts pattern right by 1 position and restarts comparison from P[0]. Inefficient on repetitive text (e.g. searching AAAAAB in AAAAAAAAAAAAAB).

    Worst Time: O((N-M+1)·M)Space: O(1)No Preprocessing
  • 2. Knuth-Morris-Pratt (KMP) Algorithm:

    Eliminates redundant comparisons by utilizing knowledge gained from previous character matches. Precomputes an LPS (Longest Prefix Suffix) array where LPS[i] stores the length of the longest proper prefix of P[0..i] that is also a suffix of P[0..i]. Upon a mismatch after matching j characters, KMP sets j = LPS[j-1] without rewinding text index i, guaranteeing strict O(N) linear time.

    Preprocessing: O(M)Search Time: O(N)Space: O(M)LPS Table
  • 3. Rabin-Karp Algorithm:

    Uses a Rolling Hash function to convert pattern and text substring windows into integer hash values. Computes H(P) and updates H(T[i..i+M-1]) in O(1) time as the window slides using modular arithmetic: H(next) = (d · (H(curr) - T[i] · d^(M-1)) + T[i+M]) % q. Only performs character-by-character validation when window hash equals pattern hash.

    Average Time: O(N + M)Worst Time: O(N·M)Rolling Hash

Real-World Applications

Genomic DNA sequence alignment in bioinformatics, IDE global code search (`Ctrl+F`), plagiarism checking software, and network intrusion detection signature filtering (NIDS).
